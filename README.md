## Project Overview

This project presents a comprehensive end-to-end data analytics and machine learning system built on 25+ years (1999–2026) of Nifty 50 stock market data. It combines rigorous data quality auditing, exploratory data analysis, technical indicator computation, multi-task machine learning prediction (regression and classification), model explainability, and a fully interactive Streamlit dashboard.

The project is intended purely for educational and research purposes. It does not constitute financial advice, and predictions generated by the models are estimates only.

---

## Objectives

1. Perform a thorough data quality audit and document all cleaning decisions.
2. Conduct comprehensive exploratory data analysis across stock, sector, year, and month dimensions.
3. Compute standard technical indicators using the `ta` library.
4. Engineer lag and rolling features without introducing data leakage.
5. Build and compare multiple machine learning models for seven prediction tasks.
6. Evaluate all models using appropriate metrics and maintain a central comparison table.
7. Explain model predictions using feature importance and permutation importance.
8. Present all results through a professional interactive Streamlit dashboard.

## Running the Merged Script (Recommended)

`Nifty50_AI_Market_Analytics.py` combines the full ML pipeline **and** the Streamlit dashboard in a single file.

```bash

# (data audit → cleaning → EDA → feature engineering → model training → eval charts)
python Nifty50_AI_Market_Analytics.py --pipeline

# Step 2 — Launch the interactive dashboard
streamlit run Nifty50_AI_Market_Analytics.py

# Run pipeline then launch dashboard in one command
python Nifty50_AI_Market_Analytics.py --pipeline --dashboard
```

The pipeline will:
1. Load the dataset from `../database/nifty50_historical_data.csv`.
2. Perform audit, cleaning, EDA, feature engineering, model training.
3. Save trained models to `models/`.
4. Save cleaned data to `outputs/cleaned_data/`.
5. Save metrics and charts to `outputs/`.

## Limitations

- **Survivorship bias**: The dataset only includes companies that were part of Nifty 50; delisted stocks are excluded.
- **Market regime changes**: Models trained on historical data may not generalize to future market conditions.
- **Fundamental data freshness**: Fundamental columns (PE, Market Cap, etc.) reflect the state at collection time.
- **Data gaps**: Some stocks have shorter histories; rolling indicators produce NaN for initial periods.
- **Leakage risk**: Columns like `52Week_High` and `52Week_Low` in the raw dataset are monitored carefully.
- **Prediction uncertainty**: All predictions carry inherent uncertainty. No model can guarantee future price movements.
